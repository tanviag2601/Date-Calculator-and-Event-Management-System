# Project Statement

## 1. Project Title

**Date Calculator and Event Management System**

---

## 2. Problem Statement

Date calculations can become error-prone because different months have different numbers of days and February depends on leap-year rules.

In addition, users may need a simple way to maintain event information such as event names, dates, and descriptions without using a complex database system.

The **Date Calculator and Event Management System** provides a Java-based solution that performs date calculations and manages event records through a simple menu-driven console interface.

The application validates dates, handles leap years, adds and subtracts days, manages events, and provides file-based storage for saving and loading event information.

---

## 3. Scope

The scope of the project includes:

### Date Processing

* Leap-year checking
* Number of days in a month
* Date validation
* Adding days to a date
* Subtracting days from a date

### Event Management

* Adding events
* Displaying all events
* Searching events
* Removing events

### Data Persistence

* Saving events to a text file
* Loading events from a text file

### User Interaction

* Menu-driven console interface
* User input
* Display of operation results

The project is implemented as a Java console application and does not currently include a graphical interface or database.

---

## 4. Target Users

The project is primarily intended for:

* Students learning Java and Object-Oriented Programming
* Users who need basic date calculations
* Users who want to maintain a small collection of event records
* Academic evaluators reviewing Java programming and OOP concepts

---

## 5. High-Level Features

### Date Calculator

The system can:

* Check whether a year is a leap year.
* Validate a given date.
* Determine the number of days in a month.
* Add days to a valid date.
* Subtract days from a valid date.

### Event Management

The system allows users to:

* Add an event.
* View all events.
* Search for an event by name.
* Remove an event by name.

### File Management

The system allows users to:

* Save events in `events.txt`.
* Load saved events from `events.txt`.
* Restore event information after it has been saved.
